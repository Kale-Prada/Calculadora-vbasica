# Calculadora básica  

**Programa que simula una calculadora**

Muestra según la opción a elegir +(suma), -(resta), *(multiplicación), /(División) de dos números ingresados por teclado por el usuario. 

## Funcionamiento: 

El programa pide que primero se ingrese un número, luego el segundo, ingresar la operación que se calcule la operación y que se vuelva a ejecutar hasta que se escriba la palabra SALIR.

**Pedirá:** ingrese primer número, ingrese segundo número y luego ingrese la operación. Y luego ingrese la operación. 

El programa debe parar solo si al final de la operación escribose escribe la palabra SALIR.

## Instalación y Ejecución

1. Clona o descarga el repositorio en tu equipo.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Crea y activa un entorno virtual:
   ```bash
    # Para crear el entorno: 
    # En Windows: 
    python -m venv entorno
    
    #Otra opción: 
    py -m venv entorno 

    # En MacOS: 
    python3 -m venv entorno

    # Para activar el entorno: 
    # En Windows:
    .\entorno\Scripts\activate

    # En macOS/Linux:
    source entorno/bin/activate
   ```
4. Instala las librerías necesarias ejecutando:
   ```bash
   # En Windows:
   pip install -r requirements.txt

   # En macOS/Linux:
   pip3 install -r requirements.txt
   ```


   ## Requerimientos
Necesitas Visual Studio Code o Pycharm para ejecutar el programa 
```bash
   # En Windows:
   py main.py 

   # En macOS/Linux:
    python3 main.py 
   ```
